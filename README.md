# Gerador-de-Senhas 
Um gerador de senhas interativo que faz suas senhas automaticamente em tempo real

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript (manipulação DOM, eventos)

## Funcionalidades
- Transforma o valor digitado como limite de quantos caracteres que por na nova senha.
- Em seguida, tem opções de criação como letras maiusculas, letras minusculas, símbolos, e números.
- Após selecionar, o gerador cria um nova senha para você, o que facilita na questão de perder tempo em pensar em nova senha.
- Além disso, que tem a opção que, depois de criar a senha, de copiar a senha clicando no botão "Copiar".

## Posíveis melhorias futuras
- Adicionar input range estilizado e intuitivo para que não haja necessidade de digitar o valor.
- Remover o botão "Gerar" e criar no momento em que algum número é digitado no input number.
